Taskronin 0.1.0 is the first public release.

Taskronin is a single-user task manager for Linux built around triage, daily
focus and a work log. New, slipped and due work enters one triage list and
leaves only by an explicit decision. Time blocks have outcomes, `tkr log`
records what you did, and `undo`, `redo` and `revert` work from a full audit
trail. It ships as one static binary, `tkr`, with a command line, a terminal
UI, a local web UI and an MCP server over a single SQLite database.

## Install

- **Debian and Ubuntu:** download `taskronin_0.1.0_amd64.deb` (or `arm64`),
  run `sudo apt install ./taskronin_0.1.0_amd64.deb`, then `tkr init`.
- **NixOS:** add the flake `github:linsomniac/taskronin`, import
  `nixosModules.default`, set `programs.taskronin.enable = true;`, rebuild,
  then `tkr init`.
- **Other Linux systems:** unpack `taskronin_0.1.0_linux_amd64.tar.gz` (or
  `arm64`), put `tkr` on your `PATH`, then `tkr init`.

The [README](https://github.com/linsomniac/taskronin/blob/v0.1.0/README.md#install)
has the details, and the
[quickstart](https://github.com/linsomniac/taskronin/blob/v0.1.0/docs/quickstart.md)
is a five-minute tour.

## What to know

- Linux only, on amd64 and arm64.
- One user on one workstation. There is no sync between machines.
- No recurring tasks and no query language in this version.
- The web UI listens on loopback only.
- This is a first release, built for its author's daily use. Copy the
  snapshots that `tkr backup` takes to another machine.
